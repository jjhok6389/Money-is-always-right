# 기능 명세서

> **문서 상태:** 기능 명세서 v1.0  
> 
**서비스:** AI 기반 청년층 맞춤형 자산 형성 및 금융상품 추천 플랫폼  
> 
**목적:** 청년층 사용자의 소득·지출·자산·부채·목표를 분석하여 저축 가능 금액, 금융상품 추천, 목표 달성 시뮬레이션 및 AI 금융 상담을 제공한다.
